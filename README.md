# Elixír Gabival – GitHub Pages

A teljes honlap kódja és képei. Telepítés és build nem szükséges.

1. Csomagold ki a ZIP-et.
2. A GitHubon hozz létre egy új, nyilvános repositoryt, például elixir-gabival néven.
3. Add file → Upload files: töltsd fel a kicsomagolt fájlokat és az assets mappát. Ne a ZIP-et töltsd fel! Az index.html közvetlenül a repository gyökerében legyen.
4. Commit changes.
5. Settings → Pages → Source: Deploy from a branch.
6. Branch: main; Folder: /(root); Save.
7. A Pages résznél megjelenő Visit site gombbal nyithatod meg a honlapot. A közzététel akár 10 percet is igénybe vehet.

A képeket tartalmazó assets mappa maradjon az index.html mellett.
A GitHub Pages-en közzétett oldal nem örökli a ChatGPT Site privát hozzáférését.
A csomag nem módosítja a meglévő Webnode-oldalt és a marczygabi.hu domainbeállításait. A saját domain csatlakoztatása külön lépés.
